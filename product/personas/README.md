# User Personas

Store user persona definitions, demographic insights, behavioral patterns, jobs-to-be-done (JTBD), and key frustration points here.

## Structure Template per Persona:
- **Role/Title**: (e.g., Team Admin, Casual Shopper, Power Analyst)
- **Goals**: What are they trying to accomplish?
- **Pain Points**: What blocks them today?
- **Technical Literacy**: Comfort level with digital tools.
- **Key Scenarios**: Typical interactions with the product.

# Frontend UI Components (`src/components/`)

Contains reusable React components structured by granularity and responsibility.

## 📂 Subdirectories
- **`ui/`**: Low-level, primitive design system components (Button, Input, Dialog, Dropdown, Tooltip). Typically backed by Radix UI or Tailwind primitives.
- **`shared/`**: Compound, cross-cutting components (Navbar, Footer, Sidebar, ThemeToggle, UserMenu).
- **`features/`**: Domain-specific UI widgets and composed sections (e.g. `billing/`, `settings/`, `analytics/`).

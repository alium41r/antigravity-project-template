# Environment Configuration

Guide for managing environment variables across development, preview/staging, and production environments.

## File References:
- **Root [`.env.example`](../../.env.example)**: The canonical template for required and optional environment variables. Copy to `.env.local` for local development.
- **[`.env.production.example`](.env.production.example)**: Reference template for production deployments (e.g. Vercel, Supabase connection poolers).

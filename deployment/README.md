# Deployment & Infrastructure

Infrastructure configurations, CI/CD automation pipelines, container definitions, and environment variable templates.

## 📂 Subdirectories
- **`ci-cd/`**: GitHub Actions / GitLab CI workflow definitions for linting, testing, building, and deploying.
- **`docker/`**: Dockerfiles and `docker-compose.yml` for local containerized development or self-hosted deployment.
- **`environments/`**: Environment variable documentation and template files (`.env.example`).
- **`infrastructure/`**: IaC definitions (Terraform, Pulumi) and platform configurations (Vercel, Supabase, Cloudflare).

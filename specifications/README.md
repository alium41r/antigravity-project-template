# Specifications

This directory houses granular, actionable feature definitions, product requirement documents (PRDs), and technical interface contracts.

## 📂 Subdirectories
- **`prds/`**: High-level Product Requirement Documents for major milestones and initiatives.
- **`features/`**: Specific functional specs, user stories, edge cases, and acceptance criteria.
- **`api/`**: OpenAPI / REST specifications, data contracts, and event schemas.

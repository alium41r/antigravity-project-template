# Operational Runbooks

Standard Operating Procedures (SOPs) for routine maintenance, incident response, and disaster recovery.

## Recommended Runbooks:
- **Database Migrations**: Zero-downtime schema evolution and rollback procedures.
- **Incident Response**: P1/P2 outage triage, escalation matrix, and post-mortem template.
- **Secret Rotation**: Process for rotating Supabase service role keys, database passwords, and API keys.
